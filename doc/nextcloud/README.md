Repository synchronized on NextCloud
------------------------------------
This directory contains files that ar produced and edited on the Dolibarr association NextCloud server.

It is synchronized manually with the command:
nextcloudcmd --path /doc-git --user eldy --password APPPASSWORD ~/git/dolibarr-foundation/doc/nextcloud https://cloud.dolibarr.org

Content can be organized into subdirectory and is open to any documentsthat need collaborative edition.
