## Repository synchronized on NextCloud
------------------------------------

This directory contains files that are produced and edited on the Dolibarr association NextCloud server.

It is synchronized manually with the command:
nextcloudcmd --path /doc-git --user LOGIN --password APPPASSWORD ~/git/dolibarr-foundation/doc/nextcloud https://cloud.dolibarr.org

Content can be organized into subdirectory and is open to any documentsthat need collaborative edition.
