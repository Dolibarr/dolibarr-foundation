## Repository synchronized on NextCloud

---

This directory contains files that are produced and edited on the Dolibarr association NextCloud server https://cloud.dolibarr.org

It is synchronized manually with the command:  
nextcloudcmd --path "Doc git" --user LOGIN --password APPPASSWORD ~/git/dolibarr-foundation/doc "https://cloud.dolibarr.org"

Content can be organized into subdirectory and is open to any documents that need collaborative edition.
